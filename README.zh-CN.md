# Brushplanner

**让你的 Procreate 笔刷，更好找、更好整理。**

[**立即使用 ↗**](https://brushplanner.cc/) · [English](README.md) · [使用指南](https://brushplanner.cc/guide)

Brushplanner 是一个在浏览器中使用的 Procreate 笔刷管理工具。导入自己的笔刷，查看原始预览，整理笔刷库与分组，再导出需要的内容。无需注册或登录。

*截图使用合成演示笔刷展示界面。*

## 可以做什么

- **集中整理笔刷**：导入 `.brush`、`.brushset`，或恢复 Brushplanner 的 `.brushlibrary` 笔刷库快照。
- **查看原始资源**：显示文件附带的笔画预览、原始 Shape 笔头和 Grain 纹理；缺失的资源会明确标注。
- **按自己的习惯分类**：创建笔刷库和多级分组，搜索、收藏、多选、移动、复制、排序与重命名。
- **保留原始名称**：默认沿用导入时的名字，想改再改；显示名称与原始名称、原始笔刷数据分别保存。
- **回收站管理**：删除后可恢复，也可在回收站中主动确认彻底删除。
- **导出与备份**：导出单支笔刷、笔刷集，或将选中的笔刷库及分组保存为 `.brushlibrary` 快照。
- **中英双语与使用导航**：切换中文或 English，跟随导航逐步认识实际操作按钮。

## 四步开始使用

1. **选择保存位置**：打开 [brushplanner.cc](https://brushplanner.cc/)，在支持的浏览器中选择本地文件夹，也可以使用浏览器本地保存。
2. **导入笔刷**：通过导入按钮选择 `.brush`、`.brushset` 或 `.brushlibrary`。选择保存文件夹不会自动导入其中散放的笔刷文件。
3. **整理与查看**：创建分组、选中笔刷进行管理，点击单支笔刷查看详情；需要改名时，点击名称旁的笔图标。
4. **导出所需内容**：选中笔刷、分组或笔刷库，再选择导出选项。迁移到其他浏览器或设备时，可用 `.brushlibrary` 保存并恢复笔刷库。

想跟着操作，可以点击工作区里的 **「使用导航与整理建议」**，或查看[完整指南](https://brushplanner.cc/guide)。

## 浏览器与本地保存

推荐使用桌面端最新版 **Edge 或 Chrome**，在 Windows、macOS 上选择普通文件夹保存。Safari 等没有普通文件夹接口的浏览器，会在支持时使用浏览器管理的本地存储；导出文件进入浏览器的下载位置。这类存储不是 Finder 或资源管理器中的普通文件夹。

笔刷解析、预览、整理与导出在浏览器中完成，不需要将笔刷文件上传到 Brushplanner 服务器。网站的其他数据处理说明见[隐私政策](https://brushplanner.cc/privacy)。

请另做备份：清理网站数据、使用无痕窗口或更换浏览器，都可能影响浏览器中保存的笔刷库。`.brushlibrary` 快照只包含所选笔刷库，不包含其他库或回收站；它是 **Brushplanner 的备份格式**。要导入 Procreate，请使用 `.brush` 或 `.brushset`。
